# 🎮 Quick Start Guide - Enhanced Games

## 🚀 Get Started in 3 Steps

### 1️⃣ Switch to Enhancement Branch
```bash
git checkout enhancement-better-games-for-tyanna
```

### 2️⃣ Start the App
```bash
npm run dev
```

### 3️⃣ Test the Games!
Click on any of these games in the app:
- 🦆 **Labyrinthe Canard** (Duck Maze)
- 🍳 **Petite Cuisine** (Cooking)
- 🚗 **Petite Voiture** (Driving)
- 🚒 **Pompier & Eau** (Firefighter)

---

## 🎯 What to Test

### 🦆 Duck Maze Game
1. Start with **Easy** level
2. Move the duck through the maze
3. Collect all items (🐟 🌸 ⭐)
4. Reach the bathtub 🛁
5. Try **Medium** and **Hard** levels!

**What's New:**
- 3D duck character
- 3 difficulty levels
- Collectible items
- Progress tracking

---

### 🍳 Cooking Game
1. Choose a recipe from the menu
2. Click on required ingredients
3. Click "CUISINER" to cook
4. Watch the pot animate!
5. Try all 5 recipes!

**Recipes Available:**
- 🥣 Vegetable Soup
- 🍳 Cheese Omelette
- 🍛 Chicken with Rice
- 🍝 Pasta Bolognese
- 🥪 Grilled Sandwich

---

### 🚗 Driving Game
1. Choose your car color
2. Click "DÉMARRER" when light is green
3. Use GAUCHE/DROITE to change lanes
4. Collect stars ⭐ coins 🪙 gifts 🎁
5. Avoid obstacles 🚧 🌳 📦

**What's New:**
- 3D car with 6 colors
- 3-lane road system
- Obstacles and collectibles
- Real-time scoring

---

### 🚒 Firefighter Game
1. Choose a mission location
2. Click on a fire to select it
3. Hold "ARROSER LE FEU" button
4. Watch water pressure!
5. Complete all 5 missions!

**Missions:**
- 🏠 House (1 fire)
- 🏫 School (2 fires)
- 🌲 Forest (3 fires)
- 🏢 Building (4 fires)
- 🏭 Factory (5 fires)
